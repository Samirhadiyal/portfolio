LLM-Eval-CI/CD

Multi-document RAG service where the eval system is the point, hybrid retrieval + reranking, LLM-judge scoring calibrated against human ground truth, and a CI/CD gate that blocks regressions, not just low scores.

View on GitHub
Key Outcomes
1 Identified and solved a common RAG blind spot: built a judge-calibration harness to verify an LLM evaluator agrees with human-labeled ground truth before trusting it as a CI/CD gate.
2 Engineered a hybrid retrieval pipeline (ChromaDB dense + BM25 sparse, fused via Reciprocal Rank Fusion) with FlashRank cross-encoder reranking to maximize context precision before generation.
3 Built a regression-aware GitHub Actions quality gate failing a PR if scores drop >5% below a stored production baseline validated across a 35-case benchmark spanning factual retrieval, multi-chunk synthesis, and guardrail cases.
